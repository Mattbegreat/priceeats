# M5 分享與引導

## 背景
沒有分享按鈕、沒有分享預覽圖（og:image）；無資料區（例：板橋座標）只建議放寬條件且都是 0 筆；餐點頁看不到同店其他餐點。

## 要做
1. 分享按鈕（結果頁、餐點頁）：用 navigator.share，不支援時複製連結；連結保留目前 URL 條件並加 ref=share。
2. Open Graph：og:title、og:description、og:image（1200x630 靜態圖，放 public/），twitter:card。靜態匯出下每頁相同即可。
3. 無資料區引導：結果 0 筆且中心距 8 區任一中心 > 3 公里時，顯示「目前只有台北東區 8 區」＋最近一區的按鈕（用 src/lib/geo haversine 算）＋「上傳菜單」入口。
4. 餐點頁：加「這家店的其他餐點」（同 restaurant_id，預算內優先，最多 10 道）。
5. 餐點頁「導航」按鈕固定在底部拇指區。

## 不能碰
- 不新增套件、不改 DB。

## 驗收
- 測試全過；新增單元測試：最近區域計算、分享連結組成。
- 線上：lat=25.0143&lng=121.4627 顯示最近區域按鈕，點了有結果。
- curl 首頁 HTML 含 og:image，圖片網址回 200。
- Matt 實機：LINE 貼連結出現標題與圖。

## 停止條件
同一錯誤修 3 次失敗就停，回報。
