## Matt 11/14 的決定
1. 產品化與資料收集平行進行。
2. 資料來源照目前方式；之後開放使用者上傳菜單，走使用者共享資源模式。
3. 成效追蹤用免費、可自訂事件的工具（候選 GoatCounter）。
4. 要買自訂網域。
5. 不做帳號系統（避免資料庫安全問題）。
6. 第一波公開台北東半 8 區，主打公司附近午餐。
