# M4 附件：整站風格「收據」（Matt 11/16 選定 B）

參考畫面：https://claude.ai/artifact/MykYHUCpuUe4k5X9wFAfKk 的「B 收據」artboard（結果頁）。M4 實作時整站改用此風格，先做完 M4 功能項再套樣式，或同一輪一起做。

## 色彩（寫成 Tailwind theme／CSS 變數，不要散落 hex）
- ground 底色 #D5DEE6（灰藍桌面）
- paper 紙 #FBFBF7（所有卡片、導覽列）
- ink 墨 #22252A（文字、分隔線、主要按鈕底）
- carbon 複寫藍 #2B4C9B（距離、次要連結）
- stamp 印章紅 #D2332B（只用在「預算內」印章、目前所在分頁、錯誤）
- leader 點線 #9AA3AD
- 紙邊陰影 #B9C4CE

## 字
- 中文：Noto Sans TC（400／500／700／900）
- 數字與金額、距離：IBM Plex Mono（500／600）。新增字型＝新增外部資源，README 要寫理由；用 next/font 或自架，不新增 npm 套件以外的相依。
- 標題 30px/900；店名 18px/900；餐點名 17px/700；金額 20px mono；預算大數字 64px mono；輔助字 13–14px。

## 元件規則
- 店家卡＝一張收據：紙色底、無圓角、底部鋸齒邊（CSS linear-gradient 做，不用圖片）、下方 2px 紙邊陰影；卡片間距 24px。
- 店名列：左店名、右距離（mono、carbon 色、單位 m），下方 2px ink 實線。
- 餐點列：左名稱、中間 2px 點線填滿、右金額（mono）。不放餐點示意圖。
- 卡片底：左「看這家全部 N 道」文字連結（44px 高、carbon、底線），右「預算內」紅框印章（旋轉 -6 度）。超出預算的餐點在展開清單中不蓋章、金額用 leader 色。
- 頁首：第一行 PriceEats／中心與距離；第二行左文案「今天的{類型}／不超過」右預算大數字；第三行筆數說明＋「改條件」膠囊按鈕（ink 底、紙色字、44px 高）。
- 篩選：按「改條件」從底部滑出紙色抽屜，樣式同收據（欄位名左、選項右）。
- 底部導覽：紙色底、上緣 2px ink 線、四項文字（找餐點／地圖／傳菜單／收藏），目前頁 stamp 色。不用圖示也可。
- 首頁：同頁首結構放大，預算快捷鍵 $50／$100／$150／$200 為 mono 數字按鈕，下方一張「範例收據」顯示該區 3 道真實餐點（資料載入後才出現，不擋操作）。
- 餐點頁：一張長收據——店名、地址、餐點與金額、價格更新日期（mono）、來源；底部固定「導航」「分享」兩顆按鈕。
- 空狀態／錯誤：收據上印「查無資料」＋下一步按鈕，不用插圖。

## 不做
- 不用漸層、不用圓角卡片陰影、不用 emoji、不用餐點示意圖。
- 動態只留抽屜開合與展開收合。

## 驗收
- 對比：內文對紙色 ≥ 4.5:1（carbon、stamp、ink 皆已符合；leader 只用於裝飾線）。
- M4 主規格的量測項全部通過（44px、無橫向捲動、第一屏 ≥ 3 張卡——收據卡較高時，第一屏 ≥ 2 家店且 ≥ 5 道餐點亦可）。
