# M4 手機體驗

## 背景
目標：單手、站著、三次點擊內看到一道買得起又走得到的餐點。11/16 實測第一屏只看得到 2 筆結果，篩選區占半個螢幕；首頁要等資料載完才出現表單。

## 要做
1. 首頁（HomeView）不等資料：表單立即可操作，資料在按搜尋後或背景載入。
2. 結果頁篩選收合：預設只顯示一列摘要（例：「$100・500m・不限」＋「篩選」按鈕），點開才展開完整面板；展開面板用底部抽屜。
3. 結果卡片在 320–430px 寬度不溢出：價格固定靠右可見，店名過長截斷。
4. 類型選中狀態：選中的類型自動捲到可見位置並高亮。
5. 定位：按「使用目前位置」被拒絕時，顯示說明並保留預設中心。
6. 加到主畫面：manifest 名稱、圖示（192／512）、theme color、display standalone 檢查並補齊。
7. 餐點示意圖：依分類顯示不同示意圖（8 類），不要全部同一張。

## 不能碰
- 不新增 UI 套件。不改資料層。

## 驗收（全部用程式量，Playwright 視窗 375x812 與 320x640）
- 首頁表單在 DOMContentLoaded 後 1 秒內可點。
- 結果頁第一屏可見結果卡 ≥ 3 張。
- document.documentElement.scrollWidth ≤ innerWidth（兩種寬度）。
- 所有 button／a／input 高與寬 ≥ 44px。
- 測試全過，新增 e2e 涵蓋以上 4 點。
- 實機（Matt）：iPhone、Android 各一次，確認定位授權與加到主畫面。

## 停止條件
同一錯誤修 3 次失敗就停，回報。
